# Workspace Agent Team

This directory contains the persistent role definitions for the project team:

- Software Architect
- Senior React Developer
- Backend Architect
- Database Administrator
- Network Engineer
- Accessibility Tester
- Security Reviewer
- Engineering Coordinator

Runtime agents are session-scoped and cannot be stored in the repository. `AGENTS.md` instructs future Codex sessions to use these definitions and activate the relevant specialists automatically. The primary agent coordinates the work and only starts the roles needed for the current feature slice or regression gate.
